# 首版功能 Demo

本目录仅包含合成数据，不含真实芯片资料、邮箱、模型地址、密钥、用户名或开发电脑路径。正式产品源码仍位于 `app/desktop/`，本目录作为 Demo 配套资料随 v1.0.0 发布，不属于普通版用户数据。

目标公司环境的完整检查和记录字段见 `ACCEPTANCE_CHECKLIST.md`。请复制模板到公司批准的位置填写，不要把含环境信息的完成记录提交到项目中。

## 演示准备

1. 双击 `release/v1.0.0/apps/demo/芯智工作台 Demo.app`；其旁边的 `演示资料/` 可直接从系统文件选择器导入。源码开发模式也可按项目根目录 `README.md` 启动。
2. 在“设置”中按需开启“受控内网连接”；不演示模型或邮箱连接时保持关闭。
3. Demo 会自动预置合成项目、星标/备注和三条进度历史；可直接查看并让已连接模型分析历史。也可另行添加 `demo/sample-project/`，索引后搜索“偏置电流”或“稳定时间”。
4. “Datasheet”会自动载入合成 PDF，可切换“PDF 原件/按页文本/AI 概略版”；也可导入 `demo/samples/synthetic_analog_ic_datasheet.pdf` 后导出 Markdown/PDF。
5. “格式转换”批量选择合成 PDF 与 `demo/sample-project/notes/verification-notes.txt`。
6. “Skills”导入 `demo/sample-skill/`，核对版本、来源和 `[prompt]` 权限后手动启用，再在智能对话中显式选择。
7. Demo 首次启动会配置“内置 Demo 模型”；无需另开终端或填写密钥。开启网络总开关后执行连接检测和流式对话。该模型只返回明确标注的确定性模拟文本，不监听端口、不会保存请求，也不能用于工程结论。源码模式仍保留 `pnpm demo:model` 作为 OpenAI 兼容协议联调服务；公司正式验收应使用内网测试端点，密钥只写入系统凭据库。
8. Demo 邮箱已预置合成邮件及 Markdown 附件，可直接阅读、搜索、预览和导出；真实收发联调必须使用专门的内网测试账户，只有测试收件人和内容复核无误后才在确认层点击发送。
9. 在“设置”导出 `.icwb` 本地备份，再选择该备份并执行第二次确认；恢复后网络总开关应自动关闭，系统凭据不会进入备份。
10. 在已添加的合成项目中展开“项目进度”，查看历史后继续保存一次；在“日历与待办”双击预置紧急任务并核对亮色加粗效果，返回项目页核对联动。已连接内置 Demo 模型时可分别生成当前建议和历史分析。
11. “知识笔记”已预置图文表格风格的 Markdown 内容；可设置本地映射目录、导入 `demo/samples/knowledge-note.md`，再导出 Markdown/PDF/DOC/DOCX。
12. “科学计算器”初始应为空白，可直接输入 `sqrt(2)^2` 并切换 DEG/RAD；“常用软件”已预置系统计算器快捷入口（系统存在时），也可选择无敏感数据的测试 `.app` 验证添加、搜索、启动和移除。

## 安全检查点

- 本机模型 Demo 只监听 `127.0.0.1`，请求上限 1 MiB，要求 `store=false`，不保存提示词、附件或响应；终端日志只显示方法、路径和状态码。
- 未开启网络总开关时，模型与邮箱连接都应由 Rust 后端拒绝。
- 项目浏览、转换、Datasheet 和 Skill 导入只读取系统对话框明确授权的本地对象。
- Skill 默认停用；含脚本或声明 `prompt` 之外权限时不能启用。
- 邮件同步以 IMAP `EXAMINE` 和 `BODY.PEEK[]` 只读执行；SMTP 发送需要独立二次确认。
- AI 生成的工程结论必须保留来源、页码、单位和条件；本 Demo 不代表 EDA 验证结果。
- 日历只使用系统时钟保持日期正确，不申请或读取系统日历权限；重点提醒仅在应用运行时出现。软件快捷入口不支持 Shell、参数、URL 或插件。

## 演示完成记录

演示人员应记录操作系统、客户端构建标识、测试日期、内网服务类型以及未通过项。不要把服务器地址、账户、邮件正文、密钥或绝对路径写入仓库。

本机模型模拟服务可用 `pnpm test:demo-model` 运行 4 项协议测试；测试仅临时监听回环地址。
