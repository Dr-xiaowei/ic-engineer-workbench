## A. 安装包与离线启动

- [ ] 使用公司确定的应用标识、版本号和正式签名身份构建，系统签名/公证校验通过。
- [ ] 对签名前、签名后的产物分别执行 `pnpm verify:artifact -- <候选包路径>`，均无私钥、环境文件、符号链接、用户名或开发路径。
- [ ] 在未安装开发工具和依赖的目标设备上完成全新安装、启动、退出和再次启动。
- [ ] 首次启动默认显示“完全离线”，未发生外网或内网连接。
- [ ] 升级安装后本地数据库可迁移，主题、会话与索引按设计保留；卸载/重装时系统凭据的保留或清除行为符合公司策略。

## B. 离线及本地功能

- [ ] 工作台正确显示最近项目、文档、对话、模型和邮箱状态；深浅主题、名称和本地头像可用。
- [ ] 添加 `demo/sample-project/` 后可浏览、增量索引、搜索“偏置电流”与“稳定时间”，预览和回答带文件位置引用，源文件未被修改。
- [ ] 导入合成 Datasheet 后可查看 PDF 原件和按页文本；AI 概略版包含概述、特性、参数、引脚/封装、应用、限制及页码来源，单位和条件未丢失；Markdown/PDF 可导出和检索。
- [ ] PDF、TXT 的单文件和批量转换可预览、另存及使用默认目录；失败输入不修改原文件。
- [ ] `demo/sample-skill/` 导入后默认停用；核对版本、来源和权限后可启用，并能在单次对话中显式选择。
- [ ] 含脚本或 `prompt` 之外权限的 Skill 无法启用或执行。
- [ ] 独立对话可创建、重命名、切换和恢复本地会话；安全 Markdown 不执行 HTML、危险协议或远程图片。
- [ ] 浮空助手只有在用户明确授权当前页面后才获得受限页面摘要，撤销授权后不继续读取。
- [ ] `.icwb` 备份/二次确认恢复成功；恢复后网络总开关关闭，备份不包含系统凭据。
- [ ] 本地审计只包含操作、结果与时间，不包含密钥、正文、服务器响应或绝对路径。
- [ ] 项目进度记录绑定已授权目录；星标、备注、起止日期、阶段、里程碑、重点、风险和百分比可保存；历史快照可查看和显式 AI 分析，关联日历待办可见，AI 不会自动修改任何字段。
- [ ] 知识笔记可搜索、编辑文本/图片/表格、映射本地目录、导入 Markdown/DOCX/PDF，并导出 Markdown/PDF/DOC/DOCX；映射外文件不被修改。
- [ ] Skills 独立清单显示作用概述、状态、版本、来源与权限，搜索和选中详情正常。
- [ ] 日历月视图自动跟随系统日期；待办可新增、单击/双击编辑、完成、删除及关联项目，紧急日程亮色加粗，重点提醒只在应用内按设定时间显示；应用不申请系统日历权限。
- [ ] 科学计算器启动为空白，可直接输入表达式；扩展按键、科学函数、DEG/RAD、历史与错误提示正确，计算过程不联网。
- [ ] 常用软件只接受测试 `.app`/可执行文件；可添加、搜索、启动、移除，普通文件、符号链接、命令和 URL 被拒绝。

## C. 公司内网模型联调

- [ ] 网络总开关关闭时，Rust 后端拒绝模型检测和对话请求。
- [ ] 仅配置本机或内网 OpenAI 兼容测试端点；公网地址、重定向目标或解析到公网的地址被拒绝。
- [ ] API 密钥只进入系统凭据库，界面、数据库、日志、备份和导出产物均无明文密钥。
- [ ] 连接检测正确显示成功/失败原因与时间；模型切换和 SSE 流式回答正常。
- [ ] 图片与文档附件边界、大小限制、来源引用和失败提示符合说明。
- [ ] 关闭网络总开关后，已检测端点不能继续发送请求；重新开启时必须由用户主动操作。

## D. 公司内网邮箱联调

- [ ] 网络总开关关闭时，Rust 后端拒绝 IMAP/SMTP 连接与发送。
- [ ] IMAPS 或强制 STARTTLS 的证书链、主机名与认证策略兼容；明文或降级连接不可用。
- [ ] 文件夹列表及非英文名称显示正确；同步使用只读方式，预览邮件不会改变服务端未读状态。
- [ ] 最近邮件、纯文本正文、本地搜索、文本/PDF/DOCX 附件预览和附件导出正确，HTML/远程资源不会自动加载。
- [ ] 写信、回复、转发和附件构信正确；未进入独立确认层时不会发送。
- [ ] 仅向专用测试收件人发送，SMTP 成功/失败提示准确；服务端 Sent 行为与产品说明一致。
- [ ] 邮箱密码只进入系统凭据库，数据库、日志、备份和导出产物均无明文凭据。
